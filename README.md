## EDA – Analyse des Ventes

Analyse exploratoire de données (EDA) sur un jeu de données de ventes, présentée sous forme de visualisations interactives accessibles dans le navigateur.


## Voir le projet en ligne : https://shillingford-laurie.github.io/eda-analyse-ventes/


## Objectifs du projet 

Explorer un jeu de données de ventes (chiffre d'affaires, produits, périodes…),
identifier les tendances, saisonnalités et KPIs clés,
restituer les résultats via des graphiques en HTML.


## Technologies utilisées

    Pyhton / Pandas
    Matplotlib / Plotly /Seaborn
    Ipywidgets / Squarify
    HTML5 / CSS3
  

## Structure du projet

```
eda-analyse-ventes/
│
├── EDA_ventes.ipynb               # Notebook d'analyse exploratoire 
├── index.html                     # Analyse écrite complète du projet (page web)
├── customers.csv                  # Données clients
├── orders.csv                     # Données commandes
├── orders_corrected_dates.csv     # Commandes avec dates corrigées
├── products.csv                   # Données produits
└── README.md
```

## Lancer en local

```bash
git clone https://github.com/shillingford-laurie/eda-analyse-ventes.git
cd eda-analyse-ventes
```

Puis ouvrir `index.html` dans votre navigateur.
